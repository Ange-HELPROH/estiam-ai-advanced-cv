# Créer un CV optimisé par IA - Mini-formation

Projet pédagogique **ÉSTIAM - AI Advanced** - Auteur : **Ange TEUFACK**.

## Contexte pédagogique validé

- **Titre** : Créer un CV optimisé par IA
- **Périmètre** : Améliorer un CV existant avec ChatGPT
- **Langue** : Français
- **Public** : Étudiants et jeunes diplômés de 15 à 30 ans
- **Durée pédagogique totale** : 18 minutes
  - **Module 1** : Diagnostiquer son CV (5 minutes)
  - **Module 2** : Améliorer son CV avec l'IA (7 minutes)
  - **Module 3** : Vérifier et finaliser son CV (6 minutes)

## Architecture du projet (compatible GitHub Pages)

```text
estiam-ai-advanced-cv/
├── index.html          # Accueil : présentation, 3 objectifs, 3 modules, Notre méthode, Bibliothèque de 5 prompts, Glossaire repliable
├── modules/
│   ├── module-1.html   # Module 1 (5 min) : 3 critères, CV initial d'Alex Martin (mention externe), analyse et exercice
│   ├── module-2.html   # Module 2 (7 min) : prompt en 5 blocs, démonstration réelle ChatGPT repliable, tableau comparatif et pratique
│   └── module-3.html   # Module 3 (6 min) : 3 contrôles, comparaison avant/après des CV, exercice et checklist en 10 points
├── css/
│   └── style.css       # Styles mobile-first et accessibles (palette #0D1B35 / #2452E8 / #6850C9 / #F8FAFC / #FFFFFF, Merriweather)
├── js/
│   └── main.js         # Menu mobile, bouton "Sommaire" repliable, suivi de section active, copie de prompts, corrigés et checklist
├── assets/
│   ├── images/         # Dossier prêt pour les illustrations pédagogiques autorisées
│   ├── videos/         # Dossier prêt pour la vidéo d'introduction (E3_Scene_01_Introduction_20s_FINAL.mp4)
│   └── docs/           # Dossier prêt pour le Handout PDF téléchargeable

```

## Utilisation locale

Ouvrir directement le fichier `index.html` dans un navigateur web moderne, ou servir la racine du projet en local.
